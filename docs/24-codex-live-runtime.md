## 使用

1. 在 SSH 页面选择 pc1 成员工作空间，确认已有共享账号。
2. 新建对话，运行时选择 Codex 原生，选择本机项目或使用独立临时工作目录。
3. 按现有翻译／预览方式发送。默认权限下，原生命令和文件修改审批显示在输入框上方，可审阅实际命令或补丁后允许本次、拒绝或取消。
4. 停止会同时请求原生中断并清理该会话创建的本机执行器进程树。停止不撤销此前已经完成的文件改动。
5. 断线或重启中的回合保留“回执待确认”。“核对原生回合结果”只读取已有原生记录，不重新发送用户请求；无法确认时维持阻断。

## 实现边界

- VPS 启动官方 `app-server`，账号认证与刷新通过已经运行的远端 broker 完成，令牌只存在远端内存。客户端不重新登录、不接收模型 token，不修改原版二进制。
- 本机启动相同版本的官方 `exec-server`，使用独立 CODEX_HOME 和最小子进程环境。工具结果、Windows 路径和 Shell 保持真实。
- SSH 密钥仅允许的固定 TCP 反向端口被旧客户端占用。因此本项目使用一次连接专属的 SSH Unix socket 转发及远端回环中继，socket 权限 0600、随机路径、随机 WebSocket 入口。未改变 `sshd`、既有密钥选项、旧客户端或固定端口。
- 每次 `turn/start` 均在桌面适配器和 VPS 入口校验唯一的本机环境与 cwd。0.155.1 的 `thread/resume` **没有** environments 参数：冷读取可返回 null，恢复响应会列出默认环境。恢复必须持有先前真实创建时保存的线程／账号／cwd／版本回执，并重新检查已连接执行器；后续回合仍显式绑定环境，不使用恢复响应中的默认目录运行工具。
- 工作台把允许字段的远端环境资料注入英文开发者说明，同时明确工具实际在 Windows 执行。该资料不构成任意脚本的系统信息隔离。
- 子 Agent／跨会话工具复用已有原生适配器；本轮没有用模型测试子 Agent、图像、hooks、全部 MCP 或所有工具类型。
- 当前本机可运行资源位于忽略的 `build/runtime/codex-0.155.1/`，本机验收回执位于 `build/qa/native-acceptance.json`。缺少资源、哈希变化或绑定不符时入口保持关闭。它不是通用安装器或其他设备的验收凭证。

## 实测证据

| 范围 | 结果 | 本机记录 |
|---|---|---|
| 无模型预检 | 远端 ChatGPT 认证、模型目录、Windows Shell 和本机 cwd 注册成功 | `build/qa/native-bootstrap-report.json` |
| 真实工具 | 读取同 owner 的 cwd 外哨兵文件、原生 apply_patch 审批、PowerShell 输出核对成功 | `build/qa/native-live-report.json` |
| 网络位置 | 同一次任务记录 VPS 原生进程持有的外部 443 连接；不把进程位置本身当出网证据 | 同上，`workbench/networkObservation` |
| 停止缺陷 | 仅 turn/interrupt 回执不能终止本机等待命令，20 秒后的写入仍发生 | `build/qa/native-cancel-report.json` |
| 修复停止 | 命令已在本机启动，清理执行器树后等待超过 20 秒，未产生延迟文件 | `build/qa/native-cancel-fixed-report.json` |
| 桌面真实操作 | 实际 Electron 输入、原生审批、补丁、本机命令、最终回复、运行动态通过；没有 renderer 异常 | `build/qa/native-desktop-live-report.json` |
| 冷恢复协议 | 冷读取不含环境，恢复返回默认列表；生产服务通过持久绑定回执和新执行器检查恢复同一原生线程，不调用模型 | `build/qa/native-resume-protocol-report.json`、`build/qa/service-session.json` |

本轮共 **6 个真实模型回合**：首次工具任务、原始取消失败、未产生流输出导致未触发取消的复测、修复后的取消复测、因桌面测试等待逻辑错误提前关闭的回合、最终完整桌面验收。失败与未完成回合没有计为通过，未做模型自动重试。其余连接和协议探测不发起模型回合。

另有一次无模型 `thread/shellCommand` 探测：该接口实际在 VPS 执行而不是选定的本机执行器，测试没有生成本机文件，**不计入取消通过证据**，生产入口不开放该方法。

本地回归包括重复提交拒绝、审批单次回应、隐藏推理不入聊天、停止等待执行器清理、断线恢复不重发、冷恢复回执不符拒绝及运行中权限锁定。全仓测试 **304/304**，桌面原有回归 **52/52**，类型检查和构建通过。

网络证据不等于厂商风控结论；Claude H、强设备隔离、完整工具覆盖和跨实体设备验收仍须单独完成。
