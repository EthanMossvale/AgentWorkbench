# 会话输入、翻译与文件预览

> 功能与验证专题；事实仅适用于正文注明的版本、日期与验证层级。当前综合状态见 [文档 16](16-implementation-status.md)。 [文档导航](README.md)

本次修改按 2026-09-27 UTC 的本地源与隔离验收记录。它没有部署 VPS、更新用户 CLI、覆盖生产 dist 或操作用户正在使用的窗口。

## 已实现的交互

- 权限菜单移除“用于下一次提交”。项目与“不关联项目”分别保存最后选择；每种运行时单独记忆，避免将某一家的权限含义套给另一家。
- Codex 运行中切换权限会立即发送原生 `thread/settings/update`，收到 CLI 成功回执后更新当前选择并记住项目或无项目偏好；原生拒绝时保留原值，不中断或重启回合。
- API 执行器允许运行中修改权限，后续工具执行前读取当前值；等待审批的命令/写入在执行前再次检查只读限制。已经启动的操作不会被描述为撤回。API 的“自动批准编辑”仍保留命令逐次审批这一独立边界。
- 运行中输入：Codex 使用 `turn/steer` 和预期回合 ID；API 在正在进行的 HTTP 请求完成后，把用户明确发送的输入加入下一次请求。没有中断/重放已有请求。过期预览不能悄悄启动新回合；未发送、已确认、回执未知分别呈现，停止后的未发送输入不会自动续投。
- 上方选择“模型来源”，条目明确区分 API 直连和 SSH 原生；下方调整该来源的模型参数。API 无需 SSH。无来源时提供添加 API、配置 SSH 和缺失运行时安装入口；没有安装的原生运行时不伪装成可选模型。
- 用户消息只保留编辑重发；分支按钮位于助手回复底部，同排提供复制回复。复制的可见回复不包含原生记忆引用元数据，原始消息仍完整保存。
- 记忆图标不执行点击动作。Codex 格式的引用元数据逐条显示引用说明与文件；Claude 仅对本轮实际成功读取的原生项目记忆显示“本轮读取”。普通文件名中包含 memory、子 Agent 的读取、失败/过期读取不能据此点亮图标。自动上下文注入却没有公开引用/读取证据时，不编造来源。这不是记忆吸收或语义正确性的证明，也不是 Claude H 已开放的声明。
- HTML 文件链接默认打开内置隔离预览，支持页面脚本、样式和有界同目录静态资源，可以查看源码或重新载入。页面不能调用工作台 preload/Node、联网、弹窗或访问系统权限；不是通用联网浏览器。普通文件保留代码与行号定位。
- 文件链接右键菜单复用已有的工作台预览、系统打开方式、另存为、复制内容、资源管理器入口，并补齐带行号路径和 Markdown 链接复制。

## 翻译开关

翻译模块开启时，每条完成的公开助手消息都会自动翻译，包含中途消息。译文面板右上角增加默认开启的“翻译中途消息”开关，样式与现有开关一致，全局生效并在重启后恢复。关闭只影响后续中途消息的自动翻译，不删除已保存译文；最终回复继续翻译。缺少阶段标签的原生末条消息在回合正常完成后按最终回复处理，不将中断的进度伪装成最终回复。原生私有推理、工具原文与签名不会被替换为译文。

## 运行中拨动原生 CLI 权限

用户最新确认的职责边界是：**工作台在运行中把权限选择提交给 CLI，具体从哪条后续请求开始使用新权限由原生运行时决定。** 不再因为当前回合可能沿用旧权限而拦截设置，也不等到下一个回合才发送。原生确认成功后更新界面与持久偏好；拒绝时不保存，连接准备中、缺失或结果未知时保留必要的连接状态检查。

仓库 Codex 0.155.1 的生成协议明确把 `thread/settings/update` 的审批策略和沙箱修改定义为后续回合设置。`turn/settings/update` 存在，但接受的是模型、思考档位、服务档位和审批审核者等字段，不接受 `approvalPolicy` 或 `sandboxPolicy`。审批审核者不是审批策略或沙箱权限。

`scripts/test-live-permissions-native.py` 使用仓库已有官方可执行文件、临时原生 HOME/CODEX_HOME 和本机合成 Responses 服务：

1. 以 `on-request` 启动一个回合，在第一次模型请求尚未返回时切换为 `never`。
2. `thread/settings/update` 返回成功，并发出已更新设置通知。
3. 同一回合接下来的两次 `exec_command` 请求仍然发起旧策略的审批；所有审批均被测试拒绝。
4. 直接把 `approvalPolicy` 传给 `turn/settings/update`，收到 unknown-field 拒绝。

上述结果记录原生内部行为，不再作为工作台阻止切换的理由。当前 Codex 接入通过既有设置接口直接拨动 CLI 权限；不会改写回合启动时的设置快照、隐藏停止/重启，或宣称已经发出的工具请求被追溯修改。

Claude 公开 Agent SDK 文档描述 `setPermissionMode` 可在运行期间调整后续工具请求，但本项目的 Claude H/公开审批控制链未验收，不能据此开放或宣称本工作台 Claude 实时切换已经完成。

原生探测报告位于忽略提交的 `build/qa/session-controls/native-live-permission-{control,probe}.json`。它验证真实原生协议与执行选择，但使用合成上游，真实付费模型调用为 0；不能等同真实 SSH/Claude H/远端部署验收。
