> 功能与验证专题；事实仅适用于正文注明的版本、日期与验证层级。当前综合状态见 [文档 16](16-implementation-status.md)。 [文档导航](README.md)

## 项目和会话

- 拖动项目标题，以细线提示插入位置。排序重启后保留；置顶区与普通区分别排序，不因拖动静默改变置顶状态。项目标题获得焦点后，也可用 Alt+↑ / Alt+↓ 调整。
- 将会话拖到项目标题或其列表区域即可移动，也可使用会话右键菜单的“移动到项目”。目标项目自动展开；原工作目录、原生线程、运行时身份、历史和执行状态保留。移动会退出原来的置顶/自定义分组，使会话出现在目标项目下；这只是整理归属，不迁移文件或重新建立执行环境。
- 项目悬停浮层显示项目名、未归档会话数、待处理/运行中数量和全部关联目录，可以直接置顶和编辑。浮层可移入操作，长路径换行，暗色和窄窗口适配。项目行快捷操作沿用侧栏提示样式。
- 项目内默认显示五条，剩余数量随“展开显示”列出。手动展开和折叠状态保存；列表刷新不会强制收起。项目区提供一键折叠/展开全部；选中被折叠或截断的历史会话时将其显示出来。
- 会话支持在当前项目、置顶区或同名分组内拖动，以细线提示前后插入位置；也可聚焦会话后按 Alt+↑ / Alt+↓。搜索结果中的调整保留被过滤会话的相对顺序。排序重启后保留，不改变工作目录、原生身份或历史。
- 日常状态刷新使用已保存顺序。只有静置**超过一小时**的会话再次出现消息、工具/原生子任务进度或运行/审批状态变化时，才按“待处理/结果未知/等待审批、运行中、未读、最近活动”重新放置该会话；其他行保持相对顺序。刚好一小时仍不触发，后续活动重新计时，持续运行但暂时没有输出的长任务不视为闲置。打开/已读、改名、翻译和设置刷新不触发排序。
- 手动调整后，当前区域的一小时保护期重新开始，避免拖动目标或相邻会话紧接着更新又打乱顺序。新建会话按既有优先级插入；项目、置顶和分组边界保留。宿主串行应用相对目标的移动请求，不用窗口提交的旧整表顺序覆盖其他窗口；拖动期间归属变化或会话被删除/归档则拒绝过期请求。

## 添加和发送附件

输入框左下角 `+` 选择文件；也可将本机文件拖到会话区域，看到“松开即可添加附件”后释放，或在输入框粘贴图片。图片显示缩略图并可打开完整预览，普通文件显示名称和大小；移除按钮只移除当前草稿引用，不删除原文件。同一草稿按名称与内容摘要去重。只添加附件、不输入文字也可发送，会话标题采用第一个文件名。

附件先保存为本机独立快照，位于工作台用户数据目录旁的 `-attachments` 目录。文件名、类型、长度和摘要由宿主生成；renderer 只能以附件 ID 引用，不能伪造待发送路径或摘要。快照是用户明确选择的上传内容，不改变模型普通文件权限。原生凭据目录、工作台配置目录、文件夹、硬链接和特殊 Windows 路径拒绝导入。输入仅进入原有 OS 文件读取权限，不扩展管理员或其他设备能力。

快照和文本一起绑定预览版本。增删附件会取消旧预览，补充修订保留附件；发送前重新读取并校验快照。附件内容不交给独立翻译服务。发送历史保留附件，可编辑重发、取消编辑和创建分支；跨模型公开交接携带附件元数据。原文件后续修改不改变已选择的快照。

支持的传输：

- Codex：图片走生成协议已核实的 `image` / `url` 输入，使用 base64 data URL，避免让远端进程把本机路径误当成远端路径。文本附件附上受界定的参考内容；大文本和其他文件给出本机快照路径供文件工具处理。实际执行仍受原有原生验收门禁约束。
- 模型 API：图片使用各协议的图片内容块；PDF 使用 Responses `input_file`、Chat Completions `file` 或 Anthropic `document`。小型 UTF-8 文本作为有明确来源边界的参考内容；大文本/其他二进制需要启用文件工具。图片/PDF 的最终可用性取决于所选服务与模型，未支持时保留错误，不自动更换来源或重发。
- 离线示例保留附件历史和界面交互，不声称运行了文件分析。Claude 原生执行门禁保持原状，Anthropic API 格式验证不是 Claude 原生执行验收。

单条消息最多 10 个附件，单文件最多 20 MiB，总计最多 50 MiB。现有原生 SSH 通道帧上限为 8 MiB，因此 Codex 单条消息图片合计上限为 5 MiB，超限在准备阶段明确拒绝。API 当前未压缩历史附件超过 100 MiB 时要求新建任务，避免无界加载。上下文估算为图片保留近似预算，不把 base64 字符数冒充真实 token；文本摘要不包含原始图片数据。

## 验证

`node --import tsx --test tests/drag-attachments.test.ts tests/native-bridge-controller.test.ts` 覆盖状态持久化、权限身份保留、快照修改检测、预览版本、重复提交、附件分支、三种 API 内容块与控制器完整发送链路，以及合成 Codex 原生帧。

`node --import tsx scripts/test-drag-attachments-ui.mjs` 生成独立构建并启动隐藏 Electron：真实 Chromium 拖拽/OS 文件路径、粘贴、原生选择器桥、缩略图、重启恢复、浅色/暗色和 860×640 浮层。测试使用临时状态和合成文件，不接管用户正在使用的窗口。

验收记录见 `build/qa/drag-attachments`（不提交构建产物）。本轮 TypeScript、全仓 578 项、专项 29 项、隐藏桌面 15 项均通过。尚未进行真实付费模型的图片/PDF 理解任务或真实 SSH 附件推理；协议和 UI 通过不能替代这些验收。
