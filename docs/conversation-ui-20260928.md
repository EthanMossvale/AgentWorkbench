## 本轮修复

### 后续补齐：数学公式与字符实体

本次检查复现 `\(\boxed{21}\)` 原样显示：原组件只识别普通 Markdown，未安装公式解析器；字符实体也只有六个硬编码名称。现在原文、译文、公开过程和子会话共用的 MessageText 接入数学 token 与 KaTeX 本地排版，支持四种常见定界符、独立 equation/align/alignat/gather 环境、分式、根号、上下标、矩阵、分段、求和积分、集合、箭头与希腊字母。HTML5 命名与数字实体使用标准解码器；普通 Unicode 符号不改写。

公式内部星号、下划线不再被外部粗体/斜体提前截断；代码、路径、金额和转义示例保留字面值。完整消息和代码复制保留原始内容。流式未闭合先显示原文，完整后排版；不支持或非法公式保留原文并标明原因，不宣称支持全部 LaTeX 宏包。长行内/块级公式在消息内滚动，不撑宽窄窗口。宏状态不跨公式共享，禁用任意 HTML、图片和链接命令，并限制输入、展开次数和尺寸。

依赖加入前分别读取 npm 包内完整 LICENSE：KaTeX 0.18.9 为 MIT，entities 8.1.0 为 BSD-2-Clause；使用锁定 npm 依赖及其随包字体，没有复制参考客户端代码或替本项目指定许可证。生产 host 构建复制两份完整许可证至 renderer/licenses；CSS 和字体随 renderer 离线打包，不请求 CDN。KaTeX 自带声明与公开文档给出 renderToString、trust、maxExpand、maxSize 和 HTML+MathML 契约，本次固定这些选项而不接受模型传入配置。

验证：Markdown/公式单测 30/30；公式专项隐藏 Electron 8/8，覆盖实际原文、译文和 NativeChildConversation、原文复制、本地字体、主题、窄窗口、流式输入、恶意输入零执行/零外网、多实例插件替换及停用恢复。原有会话交互 UI 回归 9/9；深浅与窄窗口截图已检查。证据位于忽略目录 build/qa/math-symbols。上述为本地组件与合成桥验证，不等于真实模型或在用客户端已升级。

### 原有会话交互修复

- 审批展示具体命令、目录、理由和运行时，原始请求收进“请求详情”。Codex 按原生 availableDecisions 或明确提供的策略建议展示单次、会话和保存规则；Claude 按 permission_suggestions 展示实际规则及保存位置。没有建议时不编造永久授权，不预选保存规则。
- 多题一次显示一题，保留页码、已填写状态、上一题/下一题；切页不丢失单选、多选或自定义草稿。只在最后一题提供提交，所有题目均须通过原有验证。翻译仍使用原问题索引，回答仍回到原请求。
- 已回答、拒绝和过期问题进入其原回合的过程历史，不留在底部等待区。历史记录可展开查看原稿与实际提交文本；隐私回答继续遮罩。历史按原 nativeTurnId/user message ID 归属，不因迟到时间戳进入下一回合。重连复用原生请求 ID 时保留旧记录，以独立 receipt 更新本次状态和答案。
- 原文、译文与子会话共用 Markdown 阅读组件。列表、标题、粗体、斜体、删除线、引用、表格、任务列表、行内代码与代码块按语义显示。代码框右上角复制只取框内文本，保留缩进、空行和文字字符；整条回复复制保留原始 Markdown。模型输出的 HTML 只作文字，远端图片只显示可点击引用，不自动获取。
- 修复 Responses 多个并行 function_call 转 Chat 时被拆成多个 assistant 消息的错误；现在先形成一个 tool_calls 批次，再跟随各工具结果。Claude 同一用户内容中的工具结果先于普通文字，保留严格接口要求的顺序。
- 原生明确返回 failed/result.is_error 后恢复 idle，允许用户手动发送。不会自动重试旧请求；结果未知的断线仍保留 uncertain，用户明确结束等待后才能恢复。上游 HTTP 错误增加受限的类别、错误码和参数位置，不保存原始错误正文、提示回显或凭据。

此前只保存 HTTP 状态，不能从截图追认某次历史 400 的准确原因。本轮工具消息顺序缺陷已复现并修复；不能据此声称它一定就是该次错误。

## 模型容量与原生压缩

容量来自所选上游模型目录或用户按模型文档填写的映射值；不按 Codex/Claude 名称猜测。映射编辑提供“上下文上限（tokens）”，1M 填写 1000000。手工值独立标记为 manual，刷新目录保留；切换来源或模型 ID 清除旧值。缺失时显示未知，而不是将原生默认窗口冒充模型容量。

Codex 启动同时传入真实 model_context_window 和 90% 请求预算 model_auto_compact_token_limit；0.155.1 的原生安全逻辑仍将实际阈值限制在容量的 90% 以内。验收发现单独传这两项仍会被未知模型的 272K max_context_window 截断，因此先用已安装 CLI 的 debug models --bundled 读取公开元数据，为当前模型生成临时 model_catalog_json。匹配原生名称时保留对应元数据；未知名称选用安装包内支持普通 function tools 的模板，保留原生提示及工具描述，不继承未声明的 code-mode/search 等厂商特定推理能力。目录保留其他原生项，不限制原生子 Agent 数量或层级；精确上游模型 ID 不变。不读取真实登录或聊天库，不覆盖原生配置；进程结束或准备失败后清理临时目录。未能读取安装版本目录时明确失败，不伪装 1M 生效。

Claude 使用 CLAUDE_CODE_MAX_CONTEXT_TOKENS 与 CLAUDE_CODE_AUTO_COMPACT_WINDOW。官方文档说明：已识别家族名称或带 [1m] 的 ID 会套用不同的窗口规则，MAX_CONTEXT 单独设置并非总有效。对有明确容量且会触发这些名称规则的映射，工作台使用可辨识的 awb-model- 网关内部别名；别名只供原生预算识别，网关发给上游的 model 始终是用户配置的精确 ID。不会设置 DISABLE_COMPACT，不关闭原生压缩。没有声明容量时仍保持原生名称与默认行为。

上下文控件的分母是模型容量；运行时报告的实际预算另列为 runtimeCapacity。Codex 对 1M 保留自身余量而报告 950000，不应把这两个数字混为一谈。已有运行中进程不会被新设置悄悄重启；新容量随下次进程启动应用。后台子任务仍存活而复用的进程继续使用启动时配置。声明容量不等于验证上游真正能接收该长度，填错仍会被上游拒绝。

## 90% 自动预算与小窗口复核

入口：设置 → 连接与运行 → 模型 API → 编辑连接 → 模型行“详情”。上下文上限来自上游目录或用户声明；自动压缩预算为 max(1, floor(capacity × 90 / 100))，只读、即时更新且不覆盖容量。258400 → 232560，32001 → 28800，留空表示未知。工作台不会依据运行时名或某张会话用量截图猜测真实模型容量。

90% 是提交给原生运行时的预算，不是精确触发保证。Codex 0.155.1 原生 ModelInfo 将阈值再限制到 90% 容量，工作台不虚增窗口绕过该保护。Claude Code 2.1.283 的未知自定义 ID 对百分比和 AUTO_COMPACT_WINDOW 单独覆盖未按预期降低阈值；工作台将 MAX_CONTEXT 设置为派生预算，AUTO_COMPACT_WINDOW 同步设置并遵守 100K..1M 参数范围，原生仍取模型窗口约束并预留空间。32K/64K 不会被强行提升到 100K，实际模型容量也没有被改成压缩预算。

压缩由原生 CLI 执行。第三方 provider 网关将所有请求映射到已选上游模型，包含原生摘要请求；不要求另配 Haiku、mini 或其他小模型，不增加工作台模型切换或外层重试。官方原生执行路径继续交给原生 provider 决定。核对的 Codex 源码区分 provider 支持的远端压缩和普通 Responses 摘要路径，不能据此声称其官方服务内部总用固定小模型；普通路径会用当前上下文模型。Claude 的工作台映射让家族别名均指向同一配置模型，真实请求也已核对。

2026-09-28 JST，此前 95% 预算版本的 scripts/test-native-compaction.mjs 共 19 项真实 CLI/合成上游检查通过：两家的 32K/128K/258400/400K/1M/1050000 均自动压缩并以摘要继续；Claude 64K 另核对家族/[1m] 名称别名；所有上游请求的模型 ID 精确保持不变。低用量不触发，Codex 258400 的 89% 不触发、90% 触发，Claude 的 94% 已触发，符合原生可能提前预留的边界。1050000 是任意数值夹具，不能作为特定商业模型容量证据。

前提是容量及上游 usage 准确且用户未停用自动压缩。保留 DISABLE_COMPACT、DISABLE_AUTO_COMPACT 等原生控制；显式停用对照在原生窗口保护处结束，没有工作台自动续投。真实长文本摘要质量、旧网关问题根因、官方服务内部压缩模型和任意第三方兼容性未由合成测试验证。

tests/context-budget.test.ts 覆盖只读插件预算接口与无副作用错误恢复；scripts/test-context-budget-ui.mjs 的 6 项隐藏 Electron 检查覆盖即时计算、未知值、手动容量刷新保留、保存回读与浅深/窄布局。

2026-09-28 后续按用户要求将默认预算统一为 90%。Codex 的 95% 可用窗口统计与压缩阈值独立，保持原生实报值；Claude 的进程预算随配置变为 90%。界面、只读接口、原生启动和测试期望同步调整；后续验证见实现记录。
