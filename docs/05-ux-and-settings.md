# 05 · 界面与交互设计基线

> 历史需求/设计基线；现行规则见 [AGENTS.md](../AGENTS.md)，实现与修订见 [文档 16](16-implementation-status.md)。本文旧方案不构成当前部署指令。 [文档导航](README.md)

这是文字规格，不是已经实现或视觉验收通过的界面。参考软件提供偏好方向；不复制品牌、商标、完整资产或声称官方关联。

## 1. 视觉方向

用户偏好：Claude 桌面端那种克制、暖灰、明亮的外观；另有完整暗色主题。工作流程参考 Codex 的项目与会话组织。避免玻璃炫光、霓虹、大片纯黑/纯白、高饱和渐变。

| Token（建议值） | 浅色 | 暗色 |
|---|---|---|
| 页面背景 | `#F4F3F0` | `#20211F` |
| 侧栏 | `#ECEBE7` | `#191A18` |
| 内容表面 | `#FAFAF7` | `#292A27` |
| 主文字 | `#262824` | `#EEEFE8` |
| 次文字 | `#666B62` | `#ADB2A7` |
| 细分隔线 | `#D7D9D1` | `#41453C` |
| 控件强调 | `#A44E36` | `#E49A80` |

颜色只是初稿，待对实际字体、按钮、焦点环和状态组合逐项做对比度验收；不得把候选色表写成已通过无障碍认证。主题支持浅色 / 暗色 / 跟随系统，代码块、图表、终端与弹窗必须一起适配。

## 2. 主窗口布局

左侧项目/会话树，中间会话工作区，右侧可收起的文件、diff、终端、预览。顶部或会话标题附近常驻显示：运行时、执行位置、模型出口、连接状态。

H 模式示例标签：“Codex 运行于远端 / 工具执行于本机 / 模型出口为远端”。不能只显示一个绿色 SSH 图标让用户猜文件会改在哪里。

v0.2默认以Claude主线布局；增加“环境视图：VPS profile / 观测时间”和真实执行保证标签projected、isolated或host-exposed。模型侧环境视图与实际执行位置分别显示；跨工作区访问普通文件不弹额外围栏确认。

账户切换器放全局可发现位置；当前会话的已绑定账号另行显示。这里选择的是 VPS 上的原生 CLI 账号环境，不是框架自己的 SDK 登录。换默认账号只影响新会话，不改变既有会话身份。

## 3. 左侧管理

- 全局任务、固定会话、自定义分组、项目分组、归档入口。
- 新建会话默认继承项目位置和推荐模式；允许明确选择已有项目或临时工作区。
- 同名会话以稳定 ID 区分，次级信息显示主机/目录，操作不能按标题匹配。
- 菜单：重命名、固定、移动分组、复制会话链接、打开项目、归档；删除是单独的明确动作。
- 多设备同会话显示只读/可写/等待接管；任务运行、待批准、离线、失败、完成各有明确状态。
- 项目是逻辑容器；本地和远端同名目录不会自动合并为同一位置。

## 4. 会话里的路径

路径卡片或内联引用支持复制、预览、打开、定位、跳到行；操作带明确主机归属。预览与“在文件管理器定位”不是一个动作，HTML 的源码预览与浏览器渲染也不是一个动作。

远端文件不能悄悄下载后冒充原位置。需要下载/同步时明确提示目标、覆盖行为和只读/可编辑状态。图片、PDF 等附件通过安全预览打开，未知协议和命令链接默认阻断。

## 5. 模型、强度与 Fast

原始用户截图见 [控件参考](assets/model-control-reference.png)。它只证明视觉偏好，不证明某个模型名称、强度枚举或 Fast 能力在所有账号中可用。

建议输入区控件：

1. **模型入口**：provider 分组，显示 runtime、型号与可用状态；新会话可切家，已有会话遵循固定绑定策略。
2. **强度滑块**：参考截图的胶囊轨道、刻度与圆形滑块，停靠到离散档位；档位由当前模型实际能力提供，不伪装成任意连续数值。
3. **闪电 Fast**：独立开关；不是强度滑块的最高档。不可用时禁用并说明原因；开启前给出当前可信的费用/额度提示。

拖动过程中只更新预览，松开/确认提交，避免每移动一个像素都启动请求或改运行配置。支持键盘方向键、可读标签、重置默认值和触摸操作；不能只靠颜色表达状态。

回合执行中更改设置时，显示“下回合生效”或要求中断；不能暗中重启任务。应用失败恢复上次生效值并显示错误，禁止 UI 显示已开启而运行时仍关闭。

## 6. 设置页

| 分类 | 内容 |
|---|---|
| 外观 | 主题、字号、缩放、动效、布局密度 |
| 模型与运行时 | CLI 路径/版本、原生/通用模式、能力、更新策略 |
| 账号 | 分 provider 的原生登录/退出、状态、额度来源和刷新时间 |
| 上下文 | 模型上限来源、有效预算、压缩策略/阈值、输出预留、生效时机 |
| 连接与工作空间 | 主机、管理员/用户身份、设备、授权、隔离级别 |
| 执行与网络 | 真实执行端、owner-wide文件命名空间、动作审批、出口、断线策略 |
| 环境保险 | SSH采集字段、profile来源/有效期、自动投影/物化、盘点权限、实际保证等级 |
| 双语工作流 | 独立翻译服务/协议/模型/effort、输入转英文、公开进度旁注、最终双栏、预算 |
| 数据与隐私 | 存储位置、日志保留、诊断脱敏、删除/导出范围 |

设置层级建议为应用默认 → 项目 → 新会话快照，受管理员策略限制；只显示当前 provider 真正支持的设置。运行中的 session 不被全局配置静默覆盖。

环境保险首次启用批准采集范围与物化策略，之后范围内自动识别/刷新；不得偷偷全局改电脑时区/字体等。翻译与主Agent的模型、effort、账号和费用完全分开；原文永远可查看，输入失败不静默绕过翻译发送。

## 7. 安装与账号体验

连接成功后分开显示“SSH 已验证”“运行时未安装/版本不兼容”“账号未登录”“模型可调用”“本地执行已授权”。一个绿色状态不能代表所有层都健康。

管理员入口连接后自动打开“发现的工作空间”：列出已有用户/空间、归属、CLI 版本、公钥指纹、已登记设备和是否可接管。主要按钮是“使用现有空间”“接管旧环境”“补齐缺项”“新建空间”；“删除并重建”单独置于危险操作区，不作为连接失败后的自动修复。

用户现有的 3 个用户级环境应优先被发现并可选复用，不用重新创建 3 份。未知 Linux 账号只显示候选，不冒充已识别工作空间；不提供“显示所有私钥”按钮。

安装向导分别勾选 Codex / Claude，显示发行来源、目标用户、版本、磁盘/依赖变更和回滚方案。默认不需要管理员账号即可完成已有 workspace 内允许的用户级操作；确需系统权限时另行确认。

额度卡片显示已用/剩余、重置时间、获取时间及来源；unknown 是“未知”不是“0%”。Codex 的重置卡只在官方能力可用时显示操作，Claude 未确认同等能力时不提供假按钮。

## 8. 翻译模块先行界面

在不需要SSH/CLI登录的独立页面完成：中文草稿 → 英文预览/校验 → 提交；运行中原始公开文字下方追加可选中文；最终左原文、右中文。可先用mock runtime验收状态机，随后接真实第三方翻译。没有公开思考文本时不造一份“思考”；译文失败只重译，不重跑任务。详见 [翻译模块](13-translation-module.md)。
